# ⚡ Quick Start Guide

## 🚀 Deploy ke Vercel dalam 3 Langkah

### Langkah 1: Install Vercel CLI

```bash
npm install -g vercel
```

### Langkah 2: Login

```bash
vercel login
```

### Langkah 3: Deploy

```bash
cd c:\xampp\htdocs\absen-mhs
vercel --prod
```

**Selesai!** 🎉 Website Anda sudah online!
